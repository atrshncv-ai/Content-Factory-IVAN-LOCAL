# 02 — Профиль бренда через `/setup`

**What to build:** Полный Telegram-сценарий первоначального заполнения, просмотра
и изменения профиля одного бренда. Профиль становится доступен Hermes-агентам и
готов к использованию отдельной папки базы знаний.

**Blocked by:** 01 — Hermes и защищённая Telegram-оболочка.

**Status:** done

- [x] `/setup` последовательно собирает бренд, нишу, аудиторию, продукты, географию, тон, цели, нежелательные темы и часовой пояс.
- [x] Обязательный минимум — бренд, ниша, аудитория, тон и часовой пояс; необязательные поля можно пропустить.
- [x] Повторный `/setup` показывает актуальный профиль и позволяет изменить выбранные поля.
- [x] Изменение защищено от устаревших callback и записывает Telegram ID инициатора в аудит.
- [x] Профиль хранится структурированно в Hermes workspace, а папка дополнительной базы знаний может быть пустой.
- [x] `/plan` объясняет отсутствие обязательного профиля, а конкретный `/new_video` не блокируется.
