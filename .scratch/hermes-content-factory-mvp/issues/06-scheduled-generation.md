# 06 — Фото и генерация по утверждённому плану

**What to build:** Утверждённый недельный план превращается в плановые задачи:
бот собирает фото, напоминает о пропусках, запускает сценарий за три часа до
публикации и отдаёт результат через тот же проверенный ComfyUI-маршрут.

**Blocked by:** 04 — Очередь, проверка результата, отмена и повтор; 05 — Веб-аналитика и недельный план.

**Status:** done

- [x] После утверждения бот последовательно собирает и подтверждает фото для трёх карточек.
- [x] Последнее подтверждённое фото заменяет предыдущее до старта; после старта требуется отмена и новая задача.
- [x] В воскресенье 10:00 создаётся черновик, если нет утверждённого плана; в понедельник приходит одно напоминание.
- [x] Стратегическое расписание допускает ручную правку; fallback — вторник, четверг и суббота 18:00 в часовом поясе бренда.
- [x] Задача стартует за три часа до публикации; без фото не запускается и напоминает в день генерации.
- [x] После получения просроченного фото задача автоматически продолжает работу.
- [x] Один режим применяется ко всему плану, но отдельная карточка переключается до дня генерации.
- [x] Ближайшие и просроченные плановые задачи приоритетнее `/new_video`, FIFO действует внутри одного приоритета, активный рендер не прерывается.
- [x] Плановый результат использует те же действия принятия, доработки, повтора и отмены, что и ручной ролик.
