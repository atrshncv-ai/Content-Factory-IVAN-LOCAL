# 04 — Очередь, проверка результата, отмена и повтор

**What to build:** Управляемый жизненный цикл разовых генераций: очередь из
нескольких задач, ручной или автоматический запуск, уведомления, отмена,
ограниченные повторы и восстановление после технического сбоя без бесконечных
циклов.

**Blocked by:** 03 — `/new_video`: фото, идея, Hermes и ComfyUI.

**Status:** done

- [x] Одновременно разрешены максимум три незавершённые ручные задачи; Node 1 выполняет только один рендер.
- [x] Ручной режим показывает сценарий и промпт с действиями «Утвердить и запустить» и «Доработать»; автоматический запускает сразу.
- [x] `/status` показывает короткие ID, состояния, время и позиции в очереди.
- [x] `/cancel` предлагает выбрать задачу кнопкой; ожидающая отменяется сразу, активная — после подтверждения и точечной отмены ComfyUI.
- [x] Через 30 минут отправляется одно сообщение «ещё генерируется»; через 60 минут выполняется одна проверка здоровья, отмена и автоматический повтор.
- [x] Вторая техническая неудача останавливает задачу и предлагает «Повторить / Отменить».
- [x] Готовый результат предлагает «Принять / Перегенерировать / Доработать / Отменить» и допускает не более двух пользовательских дополнительных генераций.
- [x] Перегенерация сохраняет фото, сценарий и промпт, меняя seed; доработка обновляет сценарий и промпт по текстовой обратной связи.
- [x] Недоступность Node 1 не расходует попытки; уведомления приходят сразу, через 30 минут и затем раз в шесть часов до восстановления.
