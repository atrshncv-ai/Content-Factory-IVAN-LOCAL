# 05 — Веб-аналитика и недельный план

**What to build:** Сквозной `/plan`: Hermes-парсер собирает проверяемые
веб-кандидаты, стратег выбирает три карточки, а администратор последовательно
принимает, заменяет или редактирует их и утверждает единый режим плана.

**Blocked by:** 02 — Профиль бренда через `/setup`.

**Status:** done

- [x] Парсер использует Google Trends, YouTube/Shorts, TikTok Creative Center и доступный публичный Instagram без платного обязательного API.
- [x] Результаты содержат реальные URL, даты и только доступные метрики; аналитика кэшируется на 24 часа.
- [x] При сбое используется предупреждённый снимок не старше семи дней; минимум пять кандидатов обязателен, целевое число — десять.
- [x] Стратег учитывает профиль бренда и формирует три карточки с согласованными полями и расписанием.
- [x] Карточки проверяются последовательно штатными Hermes `clarify` кнопками: «Принять / Заменить / Изменить».
- [x] Текстовая правка меняет только активную карточку; замена подбирает нового кандидата.
- [x] Итоговый план утверждается кнопкой «автоматически» или «с проверкой»; устаревшие кнопки не меняют состояние.
- [x] Прямой Instagram помечен best-effort, а исследование ChatPlace/Viral документировано и не блокирует готовый план.
