# 07 — Круглосуточная эксплуатация и сохранность

**What to build:** Система диагностирует оба узла, переживает перезапуск,
ротирует технические данные и защищает GPU-диск, не добавляя отдельную панель
управления.

**Blocked by:** 06 — Фото и генерация по утверждённому плану.

**Status:** ready-for-agent

- [ ] `/status` показывает Hermes, номер активного OpenCode-ключа без значения, Tailscale, Node 1, ComfyUI, очередь, план, последний успех и безопасную ошибку.
- [ ] При rate-limit/quota система переключается на второй ключ; первый получает cooldown 60 минут; исчерпание обоих ставит задачу на паузу.
- [ ] Незавершённые планы и задачи восстанавливаются после перезапуска, активный Comfy job сначала сверяется с историей.
- [ ] После восстановления бот сообщает обоим администраторам «система онлайн».
- [ ] Технические логи ротируются через 30 дней, ключевые действия сохраняют Telegram ID в SQLite, секреты и полные промпты не логируются.
- [ ] Ежедневно создаётся локальная резервная копия состояния Node 2 с хранением семи версий без `.env`.
- [ ] Неудачные и отменённые варианты удаляются через семь дней, временные файлы ComfyUI очищаются еженедельно, принятые результаты не удаляются.
- [ ] При свободном месте Node 1 менее 20 ГБ оба администратора получают предупреждение, а новые генерации блокируются.
- [ ] Слишком большой или недоставленный Telegram-файл остаётся на Node 1, а бот сообщает путь и причину.
