# 01 — Hermes и защищённая Telegram-оболочка

**What to build:** Запускаемый на Node 2 Hermes workspace с одним Telegram-ботом,
двумя администраторами из окружения, чистыми одношаговыми сессиями и пятью
доступными командами. На этом этапе `/status` подтверждает работоспособность
Hermes и показывает безопасную диагностическую сводку, а остальные команды
сообщают, что соответствующий сценарий ещё не настроен.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Бот принимает команды только от двух Telegram ID из окружения и молча игнорирует остальных.
- [ ] `/setup`, `/plan`, `/new_video`, `/status` и `/cancel` зарегистрированы и доступны на русском языке.
- [ ] Каждый cron/event-запуск выполняет один переход, сохраняет состояние и завершается без бесконечного агентского цикла.
- [ ] `/status` не раскрывает токены, ключи, `.env` или полные системные промпты.
- [ ] Конфигурация поддерживает два OpenCode Zen ключа по именам переменных окружения, не сохраняя значения в репозитории.
- [ ] Автоматические тесты проверяют allowlist, идемпотентность Telegram update/callback и безопасный статус.
