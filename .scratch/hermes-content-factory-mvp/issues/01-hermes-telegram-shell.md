# 01 — Hermes и защищённая Telegram-оболочка

**What to build:** Запускаемый на Node 2 Hermes workspace с одним Telegram-ботом,
одним или двумя администраторами из окружения, чистыми одношаговыми сессиями и пятью
доступными командами. На этом этапе `/status` подтверждает работоспособность
Hermes и показывает безопасную диагностическую сводку, а остальные команды
сообщают, что соответствующий сценарий ещё не настроен.

**Blocked by:** None — can start immediately.

**Status:** done

- [x] Бот принимает команды только от одного или двух Telegram ID из окружения и молча игнорирует остальных.
- [x] `/setup`, `/plan`, `/new_video`, `/status` и `/cancel` зарегистрированы и доступны на русском языке.
- [x] Каждый cron/event-запуск выполняет один переход, сохраняет состояние и завершается без бесконечного агентского цикла.
- [x] `/status` не раскрывает токены, ключи, `.env` или полные системные промпты.
- [x] Конфигурация поддерживает два OpenCode Zen ключа по именам переменных окружения, не сохраняя значения в репозитории.
- [x] Автоматические тесты проверяют allowlist, идемпотентность Telegram update/callback и безопасный статус.
- [x] Реальный Telegram API получает `setMyCommands` с пятью командами и
  русскими описаниями без ведущего `/`.
- [x] One-shot gateway получает ровно один update, маршрутизирует его через
  `HermesShell`, подтверждает callback и отправляет актуальные inline-кнопки.
- [x] Первый `bootstrap-offset` пропускает старую историю без ответов;
  последующие тики получают только новые события.
- [x] Mac launcher выполняет по одному Telegram и orchestrator tick и явно
  завершается с ошибкой при сбое любого шага.

## Comments

- Регрессия обнаружена при ручной проверке: ранняя реализация существовала
  только как stdin/stdout-контракт и не вызывала Telegram API.
- Исправление не добавляет новый framework и не создаёт бесконечный polling:
  `register-menu` вызывается один раз, `tick` — планировщиком.
- Для тестового контура достаточно `TELEGRAM_ADMIN_ID_1`; второй ID опционален
  и при наличии обязан отличаться.
