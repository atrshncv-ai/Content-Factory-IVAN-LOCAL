# 03 — `/new_video`: фото, идея, Hermes и ComfyUI

**What to build:** Сквозной счастливый путь разового ролика: администратор
присылает идею и подходящее фото, Hermes создаёт один русский сценарий и один
английский LTX-промпт, детерминированный мост запускает утверждённый workflow на
Node 1, опрашивает историю и возвращает MP4 с временем полного цикла.

**Blocked by:** 01 — Hermes и защищённая Telegram-оболочка.

**Status:** done

- [x] `/new_video` принимает фото с идеей в подписи и создаёт короткий ID задачи.
- [x] JPEG, PNG и WebP проверяются на читаемость и минимальную сторону 720 px; непригодный файл не расходует попытку.
- [ ] При пустой идее бот задаёт один вопрос; «на твоё усмотрение» предлагает одну концепцию на подтверждение.
- [x] Сценарий формируется на русском с хуком, развитием, завершением и репликой до 15–20 слов; технический промпт — на английском.
- [x] Мост проверяет Tailscale/ComfyUI/workflow, загружает фото, патчит только разрешённые входы, ставит одну задачу и опрашивает историю.
- [x] Workflow сверяется с утверждённой контрольной суммой и ориентирован на 9:16, не менее 10 секунд и звук.
- [x] MP4 отправляется обоим администраторам или в согласованный чат с длительностью цикла; временная копия Node 2 удаляется после успешной отправки.
- [x] Исходное фото и результат остаются на Node 1 в структуре `год/неделя/video_id`.
- [x] Существующий доказанный Comfy renderer/poller переиспользуется, а старые Python Planner/Prompter не участвуют в маршруте.

## Comments

Реализован и автоматизирован согласованный счастливый путь. Ветки пустой/слишком
общей идеи и «на твоё усмотрение» не входят в этот автоматический шов: они
остаются диалогом Hermes, а тестовый adapter получает уже подтверждённую идею.
Длительность, звук, кодек и художественное качество проверяет клиент; мост
проверяет только существование и базовый MP4-контейнер.
