# 03 — `/new_video`: фото, идея, Hermes и ComfyUI

**What to build:** Сквозной счастливый путь разового ролика: администратор
присылает идею и подходящее фото, Hermes создаёт один русский сценарий и один
английский LTX-промпт, детерминированный мост запускает утверждённый workflow на
Node 1, опрашивает историю и возвращает MP4 с временем полного цикла.

**Blocked by:** 01 — Hermes и защищённая Telegram-оболочка.

**Status:** ready-for-agent

- [ ] `/new_video` принимает фото с идеей в подписи и создаёт короткий ID задачи.
- [ ] JPEG, PNG и WebP проверяются на читаемость и минимальную сторону 720 px; непригодный файл не расходует попытку.
- [ ] При пустой идее бот задаёт один вопрос; «на твоё усмотрение» предлагает одну концепцию на подтверждение.
- [ ] Сценарий формируется на русском с хуком, развитием, завершением и репликой до 15–20 слов; технический промпт — на английском.
- [ ] Мост проверяет Tailscale/ComfyUI/workflow, загружает фото, патчит только разрешённые входы, ставит одну задачу и опрашивает историю.
- [ ] Workflow сверяется с утверждённой контрольной суммой и ориентирован на 9:16, не менее 10 секунд и звук.
- [ ] MP4 отправляется обоим администраторам или в согласованный чат с длительностью цикла; временная копия Node 2 удаляется после успешной отправки.
- [ ] Исходное фото и результат остаются на Node 1 в структуре `год/неделя/video_id`.
- [ ] Существующий доказанный Comfy renderer/poller переиспользуется, а старые Python Planner/Prompter не участвуют в маршруте.
