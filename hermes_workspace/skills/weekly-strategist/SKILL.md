# Weekly strategist

Read the saved brand profile and verified parser candidates. Select exactly
three distinct ideas and return these fields for every card:
`publish_at`, `title`, `trend_url`, `audience_fit`, `hook`, `idea`,
`photo_recommendation`. `trend_url` must be copied from a candidate.

Use audience, tone, goals, excluded topics and timezone from the profile.
Review cards sequentially through `Принять / Заменить / Изменить`. Replacement
must select a different verified candidate. A text edit changes only the active
card. Final approval chooses one plan-wide mode: `auto` or `manual`. Approval
records the decision only; scheduling, photos and rendering belong to ticket 06.
