# Справочник Инструментов (Tools & Skills)

Этот документ разделен на две части: инструменты, которые ТЫ (агент-разработчик) должен использовать для своей работы, и инструменты, которые ты должен интегрировать в итоговый код проекта.

## ЧАСТЬ 1: ИНСТРУМЕНТЫ ДЛЯ ТВОЕЙ РАЗРАБОТКИ (Developer Agent Tools)
Используй эти инструменты, чтобы экономить токены и писать надежный код по методологии Harness Engineering.

1. **Ponytail:** 
   - Навык ленивого Senior-разработчика. Запрещает писать лишний бойлерплейт. Твоя задача — сокращать код.
   - Ссылка: https://github.com/DietrichGebert/ponytail
2. **LeanCTX:**
   - Локальный прокси для кэширования контекста. Всегда используй его при чтении файлов проекта, чтобы снизить расход токенов на 60-90%.
3. **Superpowers (obra/superpowers):**
   - Строгий фреймворк. ТЕБЕ ЗАПРЕЩЕНО писать код до того, как ты составишь план и напишешь структуру тестов.
4. **Graphify:**
   - Инструмент для построения графов знаний из AST-деревьев кода. Используй файлы из папки `graphify-out/` для понимания архитектуры вместо слепого чтения всех .py файлов.
5. **Mark It Down (Microsoft):**
   - Если тебе нужно прочитать внешнюю документацию или PDF, сначала пропусти ее через эту утилиту для конвертации в чистый Markdown.

## ЧАСТЬ 2: ИНСТРУМЕНТЫ ДЛЯ ИТОГОВОГО ПРОЕКТА "Контент-завод" (Target System Tools)
Эти инструменты ты должен внедрить в код (в Node 2 / Hermes Agent) для обеспечения его автономности в продакшене.

1. **Scrape Creators API:**
   - Основной SaaS-инструмент для парсинга трендов Instagram/TikTok. Встраивай его вызовы в код субагента "Парсер".
2. **MarkUDown MCP:**
   - Резервный (Fallback) локальный инструмент для парсинга на базе стелс-браузера.
   - Ссылка: https://github.com/Scrape-Technology/markudown-mcp
3. **Agent Browser (Vercel):**
   - Инструмент для автономного веб-серфинга SMM-агента. Предоставь его Оркестратору для чтения статей и трендов. Он экономит токены, передавая DOM-дерево вместо тяжелых скриншотов.
4. **Claude Video (bradautomates/claude-video):**
   - Скилл/MCP для субагента-Аналитика. Позволяет скачивать видео конкурентов (YouTube/Reels), извлекать кадры и транскрибацию для анализа вирусного контента.
5. **CLI-Anything (ComfyUI Harness):**
   - Готовая консольная обертка (`cli-anything-comfyui`) для взаимодействия с API ComfyUI. Используй её для отправки заданий на генерацию медиа (Node 1) напрямую из Hermes Agent (Node 2).
