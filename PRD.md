# Product Requirements Document (PRD): Автономный контент-завод

## 1. Цель проекта
Создание полностью автономной системы для генерации контента и управления Instagram-аккаунтом. Система работает в режиме AFK (Away From Keyboard) без участия человека. 

## 2. Ключевые компоненты и бизнес-логика
*   **Сбор трендов (Парсинг):** Автоматический сбор структурированных данных о трендах через интеграцию с внешним SaaS (Scrape Creators API) или резервным MCP-инструментом (MarkUDown).
*   **Планирование контента:** Генерация идей, промптов и seed-значений на основе анализа успешных прошлых постов и текущих трендов.
*   **Генерация медиа:** Формирование заданий (JSON) для нейросетевого рендера фото и видео в ComfyUI. 
*   **Контроль качества (Evaluator):** Визуальная проверка сгенерированных фото на наличие артефактов (например, лишние пальцы). При обнаружении брака — запуск микро-цикла перегенерации до полного успеха.
*   **Публикация (SMM):** Написание постов, хештегов и автоматический постинг в Instagram через CLI-обертку стороннего сервиса автопостинга (не через прямой Graph API или UI-браузер).
*   **Аналитика и самокоррекция:** Сбор многоуровневых метрик (1 день / 1 неделя / 1 месяц) для оценки теплоты аудитории и адаптации стратегии.

## 3. Регламент надежности (Fallback)
*   **Пул API ключей:** Основной интеллект работает через облачные модели (OpenRouter/OpenAI/Claude). Менеджер ключей автоматически переключает токены при лимитах.
*   **Локальный Fallback:** В случае полного отказа API система переключается на локальную LM Studio для публикации заранее заготовленного «вечнозеленого» контента.
