# Hermes Content Factory MVP

Цель текущего этапа — два последовательных подтверждённых цикла на Mac Node 2
и клиентском Windows Node 1. Пользователь работает через один Telegram-бот:
настраивает бренд, получает/правит недельный план или создаёт разовое видео,
передаёт фото, управляет очередью и принимает MP4.

MVP включает allowlist двух администраторов, одношаговые Hermes-сессии,
сохранённый state, очередь одного GPU-рендера, утверждённый checksum workflow,
активный ComfyUI poller, recovery, backup/retention и безопасный status.

Не входят: установка Hermes на отдельный Windows-ПК клиента, автопубликация,
клонирование лица/голоса, Vision/ffprobe QC и гарантированный Instagram
scraping. Acceptance A/B и восстановление после reboot считаются выполненными
только после фактической проверки оператором с сохранённым временем и evidence.
